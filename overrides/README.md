Files here shadow the mirror in `../site` at the same URL path.

    overrides/__ext/web-assets.nousresearch.com/portal/<hash>/logo-favicon.png   -> swaps the favicon
    overrides/font/Rules/RulesVariable.woff2                                      -> swaps a font
    overrides/blog/index.html                                                     -> replaces the whole /blog page

For copy, links and brand names, prefer `../overrides.json` (string replacements) over editing HTML.
